How WebAR Try-On Works

Follow these easy steps on your phone

1

Tap "Try On Your Table"

Grants camera access to open iOS Quick Look or Android Scene Viewer.

2

Scan Your Table Surface

Slowly move your phone side to side over your table so the camera detects the flat surface.

3

Finger Gestures in AR

  • Move: Drag with 1 finger on the screen
  • Resize: Pinch with 2 fingers to scale
  • Rotate: Twist with 2 fingers to line up with plates

How to Add More Designs

Edit the JS config in this file and upload to GitHub

You don't need complex backends! Simply open your index.html file and edit the DESIGNS array at the bottom: 

const DESIGNS = [
  {
    id: 'placemat-1',
    title: 'Boho Linen Placemat',
    category: 'Placemat',
    glb: 'models/boho-placemat.glb',
    thumbnail: 'https://placehold.co/150x150/1e293b/f59e0b?text=Boho',
    defaultOrientation: '90deg 0deg 0deg' // Flattens standing models!
  },
  {
    id: 'napkin-2',
    title: 'Silk Red Napkin',
    category: 'Napkin',
    glb: 'models/red-napkin.glb',
    thumbnail: 'https://placehold.co/150x150/1e293b/ef4444?text=Silk',
    defaultOrientation: '0deg 0deg 0deg'
  }
];

Fix Standing Models:

If your 3D napkin or tissue stands vertically, set defaultOrientation: '90deg 0deg 0deg' on that item. It will lie completely flat on the table automatically!

  1. Upload your new .glb files to your GitHub repository.
  2. Add a new entry to the DESIGNS array in index.html.
  3. Commit changes. GitHub Pages automatically adds the new design card!
